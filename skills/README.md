# Skills

This folder contains shared Cortex Code skills for the Philly DMV SE team.

## How to Use

Each subfolder is a skill. To customize a skill for your customer:

1. Open Cortex Code (CoCo)
2. Tell CoCo to update the skill for your specific customer — for example:
   > "Update the demo-data skill for [customer name] using their schema and tables"
3. CoCo will tailor the skill's prompts, sample data, and configuration to match your customer's environment.

## Adding a New Skill

1. Create a new folder under `skills/` with a descriptive name (e.g., `skills/my-new-skill/`)
2. Add a `SKILL.md` file with the skill prompt and instructions
3. Push to the repo and open a PR
